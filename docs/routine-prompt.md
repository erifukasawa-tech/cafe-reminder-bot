# claude.ai Routines 設定手順

`create_trigger` API 経由ではこの組織のSlackコネクタをRoutineに持たせられなかったため、claude.ai の Routines 画面から手動で作成してください。

## 作成手順

1. claude.ai を開き、Routines(定期実行)の新規作成画面に進む。
2. 名前: `毎週金曜10:30 カフェ未予約者リマインド` など任意。
3. スケジュール: 毎週金曜 10:30 (JST)。
4. 実行方式: 「毎回新しいセッションで実行」(fresh session / 会話を引き継がない設定)を選択。
5. **コネクタ設定で Slack を必ずON にする**(これが今回API経由でできなかった部分)。
6. プロンプト欄に、下記「Routineプロンプト」の内容をそのまま貼り付ける。
7. 保存。

## Routineプロンプト

以下をそのままコピーしてRoutineのプロンプト欄に貼り付けてください。

```
あなたは「社長カフェ／ばっちさんカフェ 未予約者リマインド」を自動投稿するタスクを実行しています。これは毎週金曜10:30(JST)に自動起動される定期ジョブで、深澤恵利さん(eri_fukasawa@naikenboys.co.jp)がバックオフィス業務として毎週手動でやっていた作業を代行するものです。以下の手順を実行してください。ユーザーへの確認は不要です、自律的に最後まで実行してください。

## 手順

1. 現在時刻をJST(UTC+9)で計算し、今日の日付(月/日)を把握する。

2. Slack検索で、チャンネル `#1-全体-バックオフィスからお知らせ` (channel_id: C06A4MB1QB0) に投稿された「{今月の数字}月の社長カフェ・ばっちカフェについて」という今月分のアナウンス投稿(月初にバックオフィスが「〇月になりますので、社長カフェ／ばっちカフェの日程予約をお願いします」という内容で投稿し、対象者がスレッド返信で予約日時を報告する運用)を探す。見つからない場合(まだ月初のアナウンスが投稿されていない等)は、投稿は行わず、何もせず終了する。

3. 見つかったアナウンス投稿の thread_ts を使って `slack_read_thread` でスレッド全件(親+返信)を読む。

4. 以下の名簿と当月ルールに従い、各人の予約状況を判定する。

### 予約済み判定

スレッドの各返信は基本的に本人が自分の予約日時を報告する投稿。名簿の氏名(漢字のフルネーム、Slack表示名の中の漢字部分で照合)を投稿者(From)と突き合わせ、その人が今月割り当てられているカフェ種別について、時系列で最後に何を言っているかを見る:
- 日時を報告する投稿(例:「9/21 13:00~BA」「<@担当者> 9月25日... 入れさせていただきました」等)があれば、その時点で予約済み。
- その後に同じカフェ種別についてキャンセル系の発言(「キャンセル」「取り消し」「取消」「再度予定入れ直します」等、かつ新しい日時を伴わないもの)があれば、その時点で未予約に戻す。
- さらにその後、新しい日時の報告があれば再度予約済みに戻す。
- 一度も何も投稿していない人は未予約。

## 投稿する内容

未予約者が1人以上いるグループのみ、以下と同じ体裁でメッセージを組み立てる(全員予約済みのグループは見出しごと省略。全グループ予約済みなら投稿自体をスキップしてよい):

```
【{月}/{日}現在】未予約者

【営業】社長カフェ<@U06AJ4UHXAQ>
• (未予約者の氏名を1人1行、• 付き箇条書きで)

【マーケ】ばっちさんカフェ <@U06A4LG3SKY>
• ...

【転職】社長カフェ <@U09U94E5892>
• ...
```
(カフェ種別ラベルは当月ルールに従って実際の値に置き換えること)

このメッセージを、`slack_send_message` で **手順2で見つけた今月のアナウンス投稿と同じスレッド(thread_tsを指定)への返信**として投稿する。チャンネルへの新規トップレベル投稿にはしないこと。

投稿が完了したら、それで完了。追加の報告や確認は不要。
```

## 名簿を更新したいとき

`config/roster.json` を編集した上で、上記プロンプト内の「名簿」セクションも同じ内容に書き換えてRoutineのプロンプトを更新してください(Routineは実行のたびに新しいセッションで起動するため、プロンプト自体に埋め込まれた名簿が使われます)。
