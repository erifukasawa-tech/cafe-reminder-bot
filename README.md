# cafe-reminder-bot

毎週金曜 10:30(JST)に、Claude の定期トリガーが自動で実行する「社長カフェ／ばっちさんカフェ 未予約者リマインド」の仕様と設定を管理するリポジトリです。

実行主体はサーバーやCIではなく、Claude Code の永続トリガー(`create_trigger`)です。トリガー発火のたびに新しいセッションが立ち上がり、Slack MCP 連携を使って以下を行います。

## 何をするか

1. `#1-全体-バックオフィスからお知らせ` チャンネルで、今月分の「{N}月の社長カフェ・ばっちカフェについて」というアナウンス投稿(月初にバックオフィスが投稿し、対象者がスレッド返信で予約日時を報告する運用)を検索する。
2. そのスレッドの返信を全件読み、`config/roster.json` の名簿に載っている人ごとに、今月割り当てられているカフェ種別(社長カフェ or ばっちさんカフェ)について「予約済みメッセージ」があるかを判定する。
   - 判定は返信の時系列で行い、キャンセル発言(「キャンセル」「取り消し」「取消」「入れ直します」等)があった場合はその時点で未予約に戻し、その後に新しい日時の返信があれば再度予約済みとする。
3. 今月がどちらのカフェに該当するかは、下記の奇数月/偶数月ルールで決まる。
4. グループ(営業／マーケ／転職ぼーいず)ごとに未予約者だけを抽出し、9/17に実際に投稿された下記フォーマットと同じ体裁で、**今月のアナウンス投稿と同じスレッドへの返信**として投稿する。

   ```
   【{M}/{D}現在】未予約者

   【営業】社長カフェ<@担当者メンション>
   • 氏名
   ...

   【マーケ】ばっちさんカフェ <@担当者メンション>
   • 氏名
   ...

   【転職】社長カフェ <@担当者メンション>
   • 氏名
   ...
   ```
   全員予約済みのグループは見出しごと省略する。今月のアナウンス投稿自体が見つからない場合(月初でまだ投稿されていない等)は、投稿はせず深澤さん宛にDMで状況を伝える。

## 奇数月/偶数月ルール(2026年9月〜)

| グループ | 奇数月 | 偶数月 |
|---|---|---|
| 営業／転職ぼーいず | 社長カフェ | ばっちさんカフェ |
| マーケ／バックオフィス | ばっちさんカフェ | 社長カフェ |

出典: #1-全体-バックオフィスからお知らせ 2026-09-06 10:00 深澤さん投稿。

## 名簿の更新

`config/roster.json` を編集してください。グループの追加・削除、メンバーの増減、担当者(メンション先)の変更はすべてこのファイルで管理します。名簿を更新した場合は、Claude に「トリガーの名簿を更新して」と伝えれば、定期トリガーのプロンプトも合わせて更新します(トリガーの名簿はこのファイルのコピーを埋め込んでいるため)。

## 定期実行の仕組みについての注意

- 実行は Claude Code on the web の永続トリガー機能を使っており、cron: `30 1 * * 5`(UTC, JST 10:30 相当)で毎週金曜に新規セッションを起動します。
- Slack への投稿権限(Slack コネクタ)が必要です。接続が切れている場合はトリガーが失敗するので、深澤さんの Slack 連携が有効な状態を保ってください。
- 誤判定に気づいた場合は、まず該当週は手動で投稿を修正し、`config/roster.json` や本READMEの判定ロジックの記述を見直してください。
