# cafe-reminder-bot

毎週金曜 10:30(JST)に、Claude の定期トリガーが自動で実行する「社長カフェ／ばっちさんカフェ 未予約者リマインド」の仕様と設定を管理するリポジトリです。

実行主体はサーバーやCIではなく、claude.ai の Routines(定期実行)機能です。毎週金曜10:30(JST)にRoutineが新しいセッションを起動し、Slack MCP 連携を使って以下を行います。Routineの作成手順とそのまま貼り付けるプロンプトは [docs/routine-prompt.md](docs/routine-prompt.md) を参照してください。

## 何をするか

1. `#1-全体-バックオフィスからお知らせ` チャンネルで、今月分の「{N}月の社長カフェ・ばっちカフェについて」というアナウンス投稿(月初にバックオフィスが投稿し、対象者がスレッド返信で予約日時を報告する運用)を検索する。
2. そのスレッドの返信を全件読み、`config/roster.json` の名簿に載っている人ごとに、今月割り当てられているカフェ種別(社長カフェ or ばっちさんカフェ)について「予約済みメッセージ」があるかを判定する。
   - 判定は返信の時系列で行い、キャンセル発言(「キャンセル」「取り消し」「取消」「入れ直します」等)があった場合はその時点で未予約に戻し、その後に新しい日時の返信があれば再度予約済みとする。
3. 今月がどちらのカフェに該当するかは、下記の奇数月/偶数月ルールで決まる。
4. グループ(営業／マーケ／転職ぼーいず)ごとに未予約者だけを抽出し、9/17に実際に投稿された下記フォーマットと同じ体裁で、**今月のアナウンス投稿と同じスレッドへの返信**として投稿する。

   ```
   【{M}/{D}現在】未予約者

   【営業】社長カフェ<@担当者メンション>
   • 氏名
   ...

   【マーケ】ばっちさんカフェ <@担当者メンション>
   • 氏名
   ...

   【転職】社長カフェ <@担当者メンション>
   • 氏名
   ...
   ```
   全員予約済みのグループは見出しごと省略する。今月のアナウンス投稿自体が見つからない場合(月初でまだ投稿されていない等)は、投稿はせず深澤さん宛にDMで状況を伝える。

## 奇数月/偶数月ルール(2026年9月〜)

| グループ | 奇数月 | 偶数月 |
|---|---|---|
| 営業／転職ぼーいず | 社長カフェ | ばっちさんカフェ |
| マーケ／バックオフィス | ばっちさんカフェ | 社長カフェ |

出典: #1-全体-バックオフィスからお知らせ 2026-09-06 10:00 深澤さん投稿。

## 名簿の更新

`config/roster.json` を編集してください。グループの追加・削除、メンバーの増減、担当者(メンション先)の変更はすべてこのファイルで管理します。名簿を更新したら、`docs/routine-prompt.md` 内のプロンプトの「名簿」セクションも同じ内容に書き換え、claude.ai の Routine設定画面でプロンプトを更新してください(Routineは毎回新規セッションで動くため、プロンプトに埋め込まれた名簿がその都度使われます)。

## 定期実行の仕組みについての注意

- 実行は claude.ai の Routines 機能(毎回新規セッション)を使っており、毎週金曜10:30(JST)に起動します。作成手順は [docs/routine-prompt.md](docs/routine-prompt.md)。
- Claude Code の `create_trigger` API 経由では、このアカウントの組織設定によりSlackコネクタをRoutineに持たせられなかったため、claude.aiのRoutines画面から手動で作成する必要があります。
- Slack への投稿権限(Slack コネクタ)をRoutine作成時にONにする必要があります。接続が切れている場合はRoutineが失敗するので、深澤さんのSlack連携が有効な状態を保ってください。
- 誤判定に気づいた場合は、まず該当週は手動で投稿を修正し、`config/roster.json` や `docs/routine-prompt.md` の判定ロジックの記述を見直してください。
