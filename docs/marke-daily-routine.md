# マーケデイリー定例 自動作成 Routine

毎朝 8:46(JST)に claude.ai の Routine(毎回新規セッション)が起動し、Notion のマーケデイリー定例ページを前回分から複製して当日分を作り、「反響進捗」の売買・賃貸件数を案件管理シートから反映します。

- 実行日: 日・月・火・木・金(マーケ休業日の **水曜・土曜は作らない**)
- cron: `CRON_TZ=Asia/Tokyo 46 8 * * 0,1,2,4,5`
- 使用コネクタ: Notion, Google Sheets

## 参照先

| 対象 | 場所 |
|---|---|
| Notion DB | デイリーMTG_第5上期【使用中】 `collection://339040d1-b78a-81f0-954a-000bb05d4bf1` |
| ページタイトル形式 | `{M}/{D} マーケデイリー定例`(例: `10/2 マーケデイリー定例`) |
| 案件管理シート | `1OOOSY0Y_QDDByjkiTI9om7BOq68UfD8OdDMLqKFU6B0` |
| 売買件数 | `売買管理` シート Q列(反響日)が当月の行数 |
| 賃貸件数 | `賃貸管理` シート O列(反響日)が当月の行数 |

件数の数え方はシート上部 C3 セルの式(`=COUNTIF(ARRAYFORMULA(TEXT(Q:Q,"yyyy/mm")),TEXT(C2,"yyyy/mm"))`)と同じです。シートの「対象月」セル(C2)は書き換えず、Routine 側で当月を数えます。

## 作成手順(claude.ai の Routines 画面から手動で)

カフェリマインドと同じく、この組織では `create_trigger` API 経由で Routine にコネクタを持たせられないため、画面から作成してください。

1. claude.ai の Routines(定期実行)で新規作成。
2. 名前: `マーケデイリー定例 自動作成`
3. スケジュール: 毎週 日・月・火・木・金 の 8:46 (JST)。水・土は選ばない。
4. 実行方式: 毎回新しいセッションで実行。
5. コネクタで **Notion** と **Google Sheets** をON。
6. 下記プロンプトをそのまま貼り付けて保存。

あなたは「マーケデイリー定例」のNotionページを毎朝自動作成するタスクを実行しています。深澤恵利さん(eri_fukasawa@naikenboys.co.jp)が毎日手作業でやっていた作業の代行です。ユーザーへの確認は不要です。自律的に最後まで実行してください。

## 0. 実行日の判定
- 現在時刻をJST(UTC+9)に換算して今日の日付と曜日を出す。
- 今日が水曜または土曜なら、何もせず終了する(マーケ休業日)。

## 1. 前回ページの特定
- Notion DB「デイリーMTG_第5上期【使用中】」(collection://339040d1-b78a-81f0-954a-000bb05d4bf1)を対象にする。
- ページタイトルは「{M}/{D} マーケデイリー定例」形式(月日はゼロ埋めなし。末尾にスペースや「 (1)」が付いている場合もある)。
- 今日のタイトル「{今日のM}/{今日のD} マーケデイリー定例」のページが既にあれば、複製はせず、そのページに対して手順3の件数反映だけ行う。
- 無ければ、今日より前で最も新しい日付のページを「前回ページ」とする(通常は前営業日。例: 木曜なら火曜、日曜なら金曜)。notion-search と notion-fetch で候補を確認し、タイトルの日付で判断すること(年をまたぐ場合に注意)。

## 2. 複製と日付変更
- notion-duplicate-page で前回ページを複製する。複製は非同期なので、notion-fetch で中身が入ったことを確認してから次へ進む(入っていなければ少し待って再取得)。
- 複製ページのタイトルを「{今日のM}/{今日のD} マーケデイリー定例」に変更する(update_properties で title。「 (1)」などの接尾辞は残さない)。
- 本文はそれ以外いじらない。ただし今日が月初で、見出し「★{N}月反響進捗」のNが今月と違う場合は、その見出しの月だけ今月に直す。

## 3. 反響進捗の件数反映
- Google Sheets「案件管理シート」(spreadsheetId: 1OOOSY0Y_QDDByjkiTI9om7BOq68UfD8OdDMLqKFU6B0)を読む。シートへの書き込みは一切しない。
  - 売買件数 = 「売買管理」シート Q7:Q3010(反響日)のうち、yyyy/mm/dd 形式で今月(JST)の日付になっている行数。
  - 賃貸件数 = 「賃貸管理」シート O7:O2001(反響日)のうち、yyyy/mm/dd 形式で今月(JST)の日付になっている行数。
  - (シートC3セルの式 COUNTIF(TEXT(列,"yyyy/mm"), 当月) と同じ考え方。"9/6" のような年なしの文字列は数えない。)
- 今日のページを notion-fetch し、「★{N}月反響進捗」直下の2行を update_content で書き換える。
  - 「売買　{数字}件 /  {目標}件」の {数字} を売買件数にする(全角スペース・目標値・太字・黄色背景などの書式はそのまま。目標値は変えない)。
  - 「賃貸　{数字}件」(数字が空欄の場合もある)の数字を賃貸件数にする。
  - old_str は fetch した本文からそのままコピーした最小限の文字列を使うこと。
